# 科研图表配色

依据用户提供的四张科研图版调整，保留现有导航、字体与布局。不是任何期刊的官方主题，也不改变数据计算。

白底图面、深灰正文、细灰坐标与网格；颜色用于功能组、真实数据类别与对照角色。界面采用浅色底与对应深色文字，图形用分类色，不能用浅色直接承担正文。

| 部分 | 颜色 |
|---|---|
| 检索 | 蓝 |
| 数据与态势 | 青绿 |
| 热点与主题 | 紫 |
| 竞争格局 | 珊瑚红 |
| 技术路线 | 浅蓝 |
| 价值与机会 | 金黄 |
| 引证与同族 | 蓝灰 |
| 审计与监测 | 橙 |
| 法律与权利要求 | 玫瑰 |

图表的12个分类色来自参考图中的蓝、红、青绿、紫、橙和灰色系：`#4F75B0 #EF6E65 #73C5B7 #AC99CD #EB965E #82B6DF #D8B288 #5C9E95 #E3B7BC #C49C4A #657DA0 #959595`。聚类图、图例及主题说明使用同一主题编号映射。关系图按样本、外部、申请人及选中状态区分。

表格每5行改变浅底色、加分段线，仅帮助阅读，不表示数据分类；仍按原始顺序显示。不同结构的数据分表标题另有分类色。权利要求基准与候选原文分蓝/青绿两侧；对应、部分重合和未发现保留明确文字，不靠颜色独立传意。

所有9个功能组的正文色与浅底对比度自动检查达到4.5:1；图形继续提供图例、标签和数据表。浅色柱形补细描边，散点保留可点击原文和明确主题标签。
