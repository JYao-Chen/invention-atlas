## 项目凭据

迁移030增加项目级凭据。登录用户通过 `POST /api/api-credentials` 提交名称、`access`（read或write）及有效天数（1—365，默认90）。只读成员不能创建写入凭据。响应只在创建时返回密钥；数据库保存摘要，列表不返回密钥或摘要。

`GET /api/api-credentials` 列出本人在当前项目的凭据，`DELETE /api/api-credentials/:id` 撤销。凭据不能管理账户、组织、平台设置或其他凭据。客户端通过 `Authorization: Bearer <token>` 使用已开放的项目资源接口。每次请求重新检查账户、组织成员和项目成员状态；角色降为只读后写入凭据失效，移除项目成员会删除关联凭据。

只读凭据不能执行非GET操作，也不能通过GET触发推荐问题生成、全文模型检索或停止／重试运行。写入凭据仍受项目权限及现有资源行级隔离约束，不赋予平台管理员能力。凭据固定绑定项目，不依赖浏览器当前选择。带有无效Authorization头时，不回退使用登录Cookie。

## OpenAPI 与直接工具调用

`GET /api/openapi` 返回OpenAPI 3.1文档，需要登录会话或项目凭据。文档从实际28项工具目录及参数说明生成，覆盖项目数据集、工具能力、全部直接工具调用、结果分页、对话创建、持久分析提交、运行状态和SSE事件读取。其他项目管理接口尚未全部加入文档，不宣称全API覆盖。

直接工具调用路径为 `POST /api/tools/<工具名称>`。请求包含 `datasetId`、`params`，以及可选的 `semantic`。`semantic:false` 仅关闭检索向量调用，不能关闭权利要求抽取等其他工具的模型调用。直接调用需要读写凭据，可能产生模型费用；耗时任务应通过 `/api/runs` 提交至持久队列。缺少数据返回 `unavailable`，不能当作零统计量。

指定不存在或无权限的数据集不再回退到活动数据集。POST检查真实工具名称及必填参数，不支持的HTTP方法返回405。已保存结果通过 `/api/results/<结果编号>` 分页读取，每页最多200行，并可按word、year或图结构读取。契约说明包含字段含义及来源关联。

实际HTTP验收使用短时写入凭据及临时单记录数据集，验证凭据获取规范、真实执行数据概况、结果分页、错误数据集拒绝、必填参数验证和方法限制。没有调用付费模型；临时数据集已删除，活动数据集恢复，凭据已撤销。首次验收脚本误用Playwright的响应方法检查原生fetch，修正后通过。相关工具／凭据／规范49项测试通过，类型检查通过；新增参数最小数量说明另经规范专项验证。

包含上述最终参数说明和此前凭据空状态修正的隔离生产构建通过。此次未重新运行全部258项回归，不以49项专项测试替代全平台质量验收。

## 界面约定

“接口凭据”从工作台管理菜单打开，沿用现有工作区管理弹窗的布局与表单样式。弹窗先说明所属项目，再呈现创建表单和已有凭据；名称、只读／读写权限及有效天数属于当前项目，只读成员仅显示只读选项。创建成功后以保存密钥区域替代创建表单，提供复制操作和复制结果反馈；离开该区域须确认已保存，重新打开不恢复密钥。
