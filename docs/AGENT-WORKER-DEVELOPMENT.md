# 持久化 Agent 开发记录

## 已实现的本地基础

任务提交在同一事务内保存运行、队列及首条状态事件；同一对话的并发提交通过对话行锁串行化。队列使用领取租约和心跳，业务执行使用发起者身份及项目权限。关闭执行进程不将任务标为完成，租约到期后允许其他进程恢复。

`scripts/agent-worker.ts` 是独立执行入口。Web 和业务查询使用非表所有者的 `DATABASE_URL`；后台队列维护使用单独的 `QUEUE_DATABASE_URL`。两种连接不得互换。统一启动命令为 `npm run worker`，执行前需要完成迁移并给业务角色授予 jobs 表读写权限。

分析执行保存已完成阶段，恢复时复用成功工具结果；报告重试保留原工具产物。用户取消与进程退出分开处理，取消会保存运行终态。对话删除同时检查数据库中的运行状态与队列状态，不再仅依赖 Web 进程内标记。
