## 修复

1. 工具计划新增工具级必填参数检查，在执行前校验、必要时让规划器修正，避免缺query、strategy_id或公开编号后才失败。
2. 推荐问题将明确的目标工具和默认参数交给规划器，并在执行前补齐该推荐任务的必要参数，不让用户猜内部字段。
3. 读取、全文效果和权利要求的默认编号由当前数据集真实记录选取，表单显示编号，可调整；全文示例改为明确单项范围。
4. 监测基线按数据集隔离，首次收录标为“基线收录”，不称为互联网新增专利。
5. 时间序列图不再截断到20点；生命周期图绘制真实拟合值和观测值，诊断行不混入图。分类图超过20项时明确提示完整数据表入口。
6. 无成功工具结果时不再提供必然失败的“仅重试报告”；提供“重新运行问题”，旧失败记录保留追溯。
